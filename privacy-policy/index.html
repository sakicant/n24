Cookie policy

Use of cookies

For this website to work properly and to improve your browsing experience, it needs to store a small amount of data on your computer or access data already stored there (so-called cookie files or "cookies"). More than 90% of all websites use this practice, but under the regulations of the Republic of Croatia and the European Union we are obliged to ask for your consent before storing cookies. By using this website you agree to the use of cookies. If you block cookies you can still browse the website, but some of its features will not be available to you.

What are cookies?

A cookie (hereinafter: "cookie/s") is information stored on the User's computer by the website the User visits. Cookies usually store the User's settings and settings for the website, such as preferred language or address. When the User later visits the same website again, the browser sends back the cookies that belong to that website. This allows the website to show information adapted to the User's needs.

To ensure the website works correctly, for further development and to improve the User's browsing experience, the website stores a small amount of information (cookies) on the User's computer.

By using the website without changing the settings that would refuse consent to storing cookies on the User's computer, the User accepts the use and storage of cookies on their computer. If the User does not consent to storing cookies, they will not be stored on the User's computer, and the User will still be able to browse the website, although some features of the website will not be available.

How does this website use cookies?

This website may use cookies and store them on the User's device. We use cookies to know when and how the User uses the website, in order to improve the user experience, personalise content and show ads that are more relevant to the User. We use cookies for several purposes. To make the website work normally, show all its content and meet all technical requirements for its normal operation, we use cookies we call "Necessary cookies". Cookies that are not necessary but greatly affect the user experience we call "Statistics cookies". They let us track and analyse traffic on the website, so we can learn how the website is used.

Necessary cookies

Necessary cookies are needed for the website to display and work normally. They allow the website, its content and all its features to be shown to the User in full. Because these cookies are necessary for the website to function, they cannot be switched off on the website itself, but the User can delete or block them in their browser settings.

Statistics cookies

This website uses Statistics cookies to track overall traffic and analyse how Users use the website. For example, we collect and analyse information about visits to the website, completed forms, time spent on individual pages, devices and browsers used, geographic locations, and how Users use and behave on the website. Statistics cookies are also used to analyse effectiveness. The information collected through these cookies helps us optimise the website to improve the User's experience.

Can cookies be switched off?

Statistics cookies can be managed or switched off in the Cookie settings, while Necessary cookies are managed through the settings of the browser the User uses.

By switching off or blocking cookies, the User can still browse and use the website, but some of its features or functions may not be available.

How to disable cookies

By disabling cookies you decide whether to allow cookies to be stored on your computer. Cookie settings can be controlled and configured in your web browser.

For information about cookie settings, choose the browser you use:

  • Google Chrome
  • Mozilla Firefox
  • Microsoft Edge
  • Opera
  • Apple Safari

If you disable cookies, you will not be able to use some features of websites.

What cookies does this website use?

Some cookies are removed from the computer when the browser is closed. Websites use them to store temporary data: ci_csrfprotection_cookie, ci_session, PHPSESSID, PH_HPXY_CHECK, and the accept-cookies script.

If you use our website without changing your browser settings, we will assume that you agree to receive all cookies from our website. Most browsers let you delete individual cookies, including the cookies of our website.

There are external services that may store limited cookies for the user. These cookies are not stored by this website, or are stored so that the external service can connect to the website, and they are needed for certain features to display normally and/or for statistics. External services used on this website set certain cookies, for example for showing maps and fonts, namely: 1P_JAR / google.com, APISID / google.com, CONSENT / google.com, HSID / google.com, SAPISID / google.com, NID / google.com, SID / google.com, SIDCC / google.com, SSID / google.com, _ga / google.com, _gat / google.com, _gid / google.com.

What data does this website collect through cookies?

To store and use cookies, the website collects and processes the following User data: IP address, data about use of the website, and data about the User's behaviour and habits.

Where can I find out more about cookies?

If you have further questions about cookies or how the website collects and uses them, please email nekretnine24@n24.hr.
